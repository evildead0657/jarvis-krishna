# 🤖 JARVIS: The Human Operating System

A highly advanced, web-based personal AI assistant integrating real-time speech recognition, LLM processing, and dynamic voice synthesis.

## 🚀 System Architecture
- **Frontend:** HTML5, CSS3 (Glassmorphism UI), Vanilla JavaScript
- **Voice Engine:** Web Speech API (Speech-to-Text & Text-to-Speech)
- **AI Brain:** Google Gemini 1.5 Flash / Groq (LLaMA 3) via REST API
- **Hosting:** GitHub Pages

## ⚙️ Features
- Real-time continuous listening.
- Secure, local API key storage (No server-side tracking).
- Modular design for future backend automation integration.

## 🛠️ Setup Instructions
1. Clone this repository or add to the home screen as a PWA.
2. Open Settings.
3. Enter your Gemini or Groq API Key.
4. Tap the core and speak!
